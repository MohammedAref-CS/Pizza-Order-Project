# 🍕 Pizza Order Application

A desktop application built using C# and Windows Forms to simulate a complete pizza ordering system.

---

## ✨ Features

* **Login Screen:** A secure and welcoming entry interface with a clean background design.
* **Make Your Pizza:** An interactive order screen allowing users to choose:
  * Pizza Size (Small, Medium, Large)
  * Crust Types (Thin or Thick)
  * Toppings (Extra Cheese, Mushrooms, Onions, Olives, Tomatoes, Green Peppers)
  * Where to Eat (Eat In or Take Out)
* **Order Summary:** Real-time tracking and automatic price calculation based on user selections.
* **Pizza Menu:** A dedicated reference screen showing all available options and prices.
* **Final Bill:** A summary invoice displaying all chosen order specifications and the total cost.

---

## 🛠️ Tech Stack

* **Language:** C#
* **Framework:** Windows Forms (.NET)
* **IDE:** Visual Studio
